## Inside Aid4Mail

Aid4Mail is a local Windows mail conversion app with a named aid desk, a short conversion list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a mailbox you already own and holds only the store that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra stores wait for their own title. Aid4Mail starts with a local profile and does not need a complex account system.

## Quick Start with Aid4Mail

1. Open the last Aid4Mail session on a mailbox you own, not a new empty store.
2. Read the aid desk and the last handoff.
3. Finish one visible conversion inside Aid4Mail.
4. Write what changed, then close with a shorter conversion list than you found.
5. If the desk feels crowded, drop anything that belongs to a different mailbox.
